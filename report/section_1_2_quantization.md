## 1.2 梯度通信压缩方法

本节在第 1.1 节 FSDP 通信瓶颈分析的基础上，系统梳理本课题在后向梯度通信压缩方面的研究进展。重点包括：梯度通信压缩的研究背景与问题定义、基于 FSDP 通信钩子的模块化压缩框架，以及在该框架下已实现的量化与稀疏化算法族及其在训练过程中的作用机理。

### 1.2.1 研究背景与动机

在数据并行的分布式深度学习中，各计算节点在每轮迭代结束时需要对本地计算得到的梯度进行聚合，以更新全局模型参数。对于参数规模在数十亿乃至百亿量级以上的大模型，完整梯度向量的维度极高，且在 FSDP 框架下，每一步后向传播都会在多个 FSDP 单元上触发梯度归约操作。随着模型参数量与参与训练的 GPU 数量同步增加，**后向阶段梯度通信的带宽与延迟逐渐成为训练时间的主要瓶颈**。

从信息传输的角度看，梯度通信的开销由两个维度共同决定：一是**待传输的数据量**，包括参与同步的梯度元素数量及其表示所需的比特数；二是**通信拓扑与带宽条件**，例如单机多卡与多机多卡环境下的 NVLink、PCIe 及以太网链路。通信压缩的基本思路是通过在不显著破坏梯度统计性质与收敛行为的前提下，减少每轮同步中需要跨设备传输的有效信息量，从而降低 wall-clock 时间上的通信开销。

现有文献表明，可以从两个正交方向对梯度通信进行压缩：（1）**量化（quantization）**：在不改变向量维度的前提下，使用更少的比特数表示每一个梯度分量，从而降低单位元素的通信代价；（2）**稀疏化（sparsification）**：仅传输部分“重要”的梯度分量及其取值，将其余分量在解码端视为零，从而直接减少参与通信的分量数量。前者侧重解决“每个元素太贵”的问题，后者则从“并非所有元素都值得传”的角度出发，两者在偏差、方差、实现复杂度和理论收敛性之间形成不同的权衡。

在 FSDP 训练流程中，通信压缩主要插入于后向传播阶段梯度归约 `reduce_scatter` 的路径上：各 rank 先在本地得到对应 FSDP 单元的完整扁平梯度，再通过通信钩子执行压缩编码和可选的误差反馈（Error Feedback，EF），之后调用底层 collective 完成梯度聚合，最后在各 rank 上解码并写回本地梯度分片。因此，本课题的研究重点可以概括为：**在 FSDP 后向梯度通信路径中，设计并实现一套可插拔的量化与稀疏化算法族，在显著降低梯度通信量的同时，尽可能保持模型收敛速度与最终精度**。

### 1.2.2 模块化通信压缩框架

需要指出的是，现有文献中的大多数通信压缩算法往往与特定的训练框架或实现环境深度耦合，例如假定参数服务器架构、单一 All-Reduce 通信模式，或依赖自定义的梯度聚合逻辑，因而难以在不做大幅改动的情况下直接迁移到 PyTorch FSDP 的分片梯度 `reduce_scatter` 路径之中。为解决这一适配问题并在统一平台上对比不同压缩方法，本课题围绕 PyTorch FSDP 的 communication hook 机制，设计并实现了一个模块化的通信压缩框架。该框架的核心思想是将“**训练主逻辑**”与“**通信压缩策略**”解耦，使得不同压缩算法可以在不修改训练循环与模型定义的前提下自由切换与组合。

在实现层面，通信压缩框架包含若干相互配合的组成部分。首先，在 FSDP 中，每个通信钩子均遵循如下抽象接口：
\[
\texttt{hook}:\ (\texttt{state},\ g_{\text{full}},\ g_{\text{shard}})\ \mapsto\ \text{None},
\]
其中 \(\texttt{state}\) 为特定算法的状态对象，\(g_{\text{full}} \in \mathbb{R}^d\) 为当前 FSDP 单元的完整扁平梯度，\(g_{\text{shard}} \in \mathbb{R}^{d/M}\) 为当前 rank 上待写入的梯度分片缓冲区（\(M\) 为 world size）。Hook 内部负责完成“压缩 → 通信 → 解码 → 写回分片”的全过程。

其次，各压缩算法通过各自的状态类（如 `GradQuantState`、`TopKState`、`SketchState` 等）维护必要的超参数和运行时统计量，包括量化级数、稀疏率、误差反馈残差张量以及是否启用本地或全量误差反馈等。误差反馈在统一的残差更新公式下实现：
\[
\widetilde{g}_t = g_t + e_t,\quad q_t = C(\widetilde{g}_t),\quad e_{t+1} = \widetilde{g}_t - D(q_t),
\]
其中 \(C(\cdot)\) 与 \(D(\cdot)\) 分别为压缩与解压算子，\(e_t\) 为上一轮残差。残差既可以按完整梯度维度维护，也可以仅按本 rank 分片维度维护，以减少附加显存开销。

再次，框架通过集中式构建函数 `build_comm_hook(name, ...)` 完成压缩算法的注册与选择，将不同算法名称映射到各自的状态类与 hook 函数对（如 `fsdp_quantized_comm_hook`、`fsdp_nc_comm_hook`、`fsdp_topk_comm_hook` 等）。训练入口脚本通过命令行参数 `--comm-hook {none,int8,qsgd,nc,topk,randomk,thresholdv,sketch,onebit,...}` 选择具体方法，并传入统一的配置项（如 `--comm-topk-ratio`、`--comm-qsgd-s` 等），构建出对应的 `state` 与 `hook`，再调用 `model.register_comm_hook(state, hook)` 完成注册。

最后，为支持后续的系统性评估，框架在公共通信路径（包括密集 `reduce_scatter`、稀疏 all-gather 以及 all-to-all 等）上集成了轻量级通信统计器，对每一步后向梯度通信的有效负载字节数进行累计，并与 `torch.profiler` 生成的通信时间统计结果对应，从而形成“字节数—时间—训练质量”三方面可对比的指标体系。在上述模块化设计下，不同量化与稀疏化算法在接口层面保持一致，仅在状态对象内部逻辑和 hook 函数的具体实现上有所区别，从而大幅降低了扩展新算法与进行公平对比实验的工程成本。

### 1.2.3 所实现的压缩算法

在统一框架之上，本课题围绕“降低比特数”和“降低参与通信的梯度分量数”两个方向，分别实现了多种量化与稀疏化方法。下文按类别对主要算法进行概述。

#### 1.2.3.1 量化类方法

量化类方法在不改变梯度维度的前提下，通过减少每个梯度分量的表示比特数来压缩通信量。本课题已实现的量化方法主要包括 INT8 对称量化及其动态树变体、QSGD 随机量化、Natural Compression（NC）以及 1‑bit/Seide 形式等代表性方案。

在线性 INT8 量化中，对梯度向量 \(g \in \mathbb{R}^d\) 选取尺度
\[
s = \frac{Q_r}{\max_i |g_i| + \varepsilon},
\]
其中 \(Q_r\) 为可表示的最大整数级（例如 \(Q_r=127\) 或在考虑多卡求和溢出风险时选取更保守的值），\(\varepsilon\) 为防止除零的微小常数。量化与解码过程为
\[
q_i = \mathrm{clip}(\mathrm{round}(g_i \cdot s), -Q_r, Q_r),\quad \widehat{g}_i = q_i / s.
\]
在 FSDP 集成中，各 rank 在本地计算尺度并通过一次 all-reduce(max) 获得全局一致的尺度后，将扁平梯度量化为 int8 张量，经 `reduce_scatter(sum)` 聚合，再按尺度与 world size 反缩放得到平均梯度分片。在线性 INT8 的基础上，动态树 8‑bit 采用了一种基于“级别”的随机量化方式：首先使用同样的全局最大值作为尺度 \(\mathrm{scale} = \max_i |g_i|\)，对每个梯度分量计算归一化幅值 \(u_i = |g_i|/\mathrm{scale} \in [0,1]\)，然后将 \(u_i\) 映射到 \([0,127]\) 区间并进行 7 比特随机舍入，即令 \(l_i^\ast = u_i \cdot 127\)，在 \(\lfloor l_i^\ast \rfloor\) 与 \(\lceil l_i^\ast \rceil\) 之间按线性插值概率进行抽样得到整数级别 \(l_i \in \{0,\ldots,127\}\)，最后与符号 \(\mathrm{sign}(g_i)\in\{-1,1\}\) 相乘形成带符号级别 \(\tilde{l}_i = \mathrm{sign}(g_i)\cdot l_i\)。通信阶段，各 rank 对 \(\tilde{l}\) 向量执行 `reduce_scatter(sum)` 得到本地分片的带符号级别和，解码时再按
\[
\widehat{g}_i \approx \frac{\tilde{l}_i}{127}\cdot \frac{\mathrm{scale}}{M}
\]
恢复该分片上的平均梯度，其中 \(M\) 为 world size。与线性 INT8 相比，动态树 8‑bit 在保持 8 比特存储预算与一次 `reduce_scatter` 通信模式不变的前提下，通过 7 比特随机级别与 1 比特符号的组合，更精细地刻画了不同幅值区间内的梯度分布，其设计动机与若干动态树量化文献中提出的“用树状码本对大幅值坐标进行更密集刻画”是一致的。

QSGD 将每个梯度分量随机舍入到有限个离散级，在期望意义下保持无偏。对非零梯度向量 \(g\)，选取级数 \(s\)，有
\[
C_{\mathrm{QSGD}}(g_i) = \|g\|_2 \cdot \mathrm{sign}(g_i) \cdot \xi_i(g,s),
\]
其中 \(\xi_i(g,s) \in \{0,1/s,\ldots,1\}\) 的分布由 \(|g_i|/\|g\|_2\) 所在的量化区间决定，保证 \(\mathbb{E}[C_{\mathrm{QSGD}}(g)] = g\)，并对量化方差给出上界。在本课题实现中，既支持按整向量范数量化的“全局 QSGD”，也支持按固定大小桶分别量化的“分桶 QSGD”，后者在数值精度和实现灵活性之间提供了更好的折中。通信层面，可以选择以 16 比特通道承载量化值（float16 或 int16），也可以将量化级别进一步编码为紧凑的 bit 串，经 all-to-all 交换后在本地解码。

在“整向量 QSGD”模式下，本实现将当前 FSDP 单元的完整扁平梯度 \(g\) 视为一个整体，只计算一次全向量 \(\ell_2\) 范数 \(\|g\|_2\)，并对每个梯度分量应用上述随机量化算子 \(C_{\mathrm{QSGD}}\)。也就是说，先将 \(g\) 归一化为 \(v = g / \|g\|_2\)，再按照 \(v_i\) 在区间 \([0,1]\) 上的位置随机舍入到 \(s\) 个离散级之一，最后将量化结果缩放回原尺度，这与原始 QSGD 论文中“整向量范数 + 统一级数”的设定一致。当 `bucket_size` 配置为非正值或不小于向量长度时，代码会自动退化到这种整向量模式；当 `bucket_size` 取正且远小于向量长度时，则对每个桶单独估计范数并独立做 QSGD 量化，从而在数值上更好地适应不同子块梯度的尺度差异。对于低比特通信路径，量化后的结果还会进一步编码为紧凑的 bit 串：每个分量的取值来自集合 \(\{-1,-(s-1)/s,\ldots,(s-1)/s,1\}\)，因此可用一个“级数索引” \(\ell_i \in \{0,\ldots,s\}\) 配合一个符号位表示，对应的比特数为
\[
\text{bits\_per\_elem} = 1 + \lceil \log_2(s+1) \rceil,
\]
代码中通过函数 `_qsgd_bits_per_elem(s)` 计算该值。具体实现时，每个桶首先将其范数以 4 字节浮点数形式写入缓冲区开头，随后将所有坐标的“符号位 + 级数索引”顺序打包到连续的字节流中，通过 all-to-all 在各 rank 之间交换这一紧凑表示；解码阶段再逐桶读取范数，按上述位宽拆出符号与级数，恢复出对应的量化值。这样一来，给定级数 \(s\) 后，单坐标所需比特数由 \(\text{bits\_per\_elem}\) 精确定义，bit 串长度也随之确定，从而在保持 QSGD 随机量化性质的同时，将通信负载显式控制在 \(O(\text{bits\_per\_elem} \cdot d)\) 的量级。

Natural Compression（NC）采用与浮点指数结构天然契合的非均匀码本，将每个梯度分量 \(g\) 随机舍入到邻近的两个二次幂之一。对 \(g \neq 0\)，记 \(\alpha = \log_2 |g|\)，则
\[
C_{\mathrm{nat}}(g) = 
\begin{cases}
\mathrm{sign}(g)\cdot 2^{\lfloor \alpha \rfloor}, & \text{以概率 } p(g),\\
\mathrm{sign}(g)\cdot 2^{\lceil \alpha \rceil}, & \text{以概率 } 1-p(g),
\end{cases}
\]
其中 \(p(g)\) 的构造保证压缩算子无偏且二阶矩增幅受控。NC 本身不依赖额外的全局尺度标量，适合多机多卡环境下的去中心化实现。本课题在 FSDP 中实现了两条 NC 通信路径：其一直接在 float32 上逐分量应用 \(C_{\mathrm{nat}}\) 后通过 `reduce_scatter(sum)` 聚合；其二将 \(C_{\mathrm{nat}}\) 的结果打包为 9 比特编码（1 比特符号 + 8 比特指数），通过 all-to-all 交换后解码并求和，通信量约为 float32 baseline 的 \(9/32\)。此外，为进一步减轻 NC 在低比特情形下对收敛性的影响，实现中还引入了可选的范数缩放机制：在量化前首先对全局梯度向量计算
\[
\|g\|_2 = \Bigl(\sum_i g_i^2\Bigr)^{1/2},
\]
再在各 rank 之间通过一次 all-reduce(sum) 汇总得到全局范数 \(\|g\|_{2,\mathrm{global}}\)，随后使用缩放因子 \(\mathrm{scale} = 1 / \max(\|g\|_{2,\mathrm{global}}, \varepsilon)\) 将梯度归一化到单位球上，即令 \(g' = \mathrm{scale} \cdot g\)，并在 \(g'\) 上应用 \(C_{\mathrm{nat}}\)。解码阶段先完成各 rank 的解压与聚合，再将得到的平均梯度分片除以 \(\mathrm{scale}\) 恢复到原始尺度。直观上看，范数缩放将量化过程限制在一个统一的归一化空间中，避免不同 batch 或不同层之间梯度范数差异过大导致的小分量系统性被舍入为零，从而在保持通信量优势的同时，降低了 NC 对损失曲线和收敛速度的不利影响；结合误差反馈使用时，这一机制尤为有效。

1‑bit 量化则将每个坐标压缩为单个符号位 \(q_i = \mathrm{sign}(\widetilde{g}_i)\)，并配合少量标量尺度参数恢复近似梯度，例如 \(\widehat{g}_i = \mu q_i\)，其中 \(\mu\) 可取为 \(\ell_1\) 范数均值或分桶局部均值。Seide 形式进一步在每个块上维护正负两类分量的均值 \(a,b\)，通信阶段仅发送符号与 \((a,b)\)，解码时根据符号从二者中选择重构值，在保持 1‑bit 通信的前提下降低重构误差。由于此类方法本质上为强有偏压缩，因此误差反馈几乎是必需组件，残差张量的显存开销与实现复杂度也相应较高，更适合通信瓶颈极为突出的部署场景。

上述量化方法均在 FSDP 后向梯度归约路径上通过通信钩子插入，输入为完整梯度向量，输出为当前 rank 的平均梯度分片。不同方法在压缩比、量化误差及计算开销之间形成不同折中，为后续实验对比提供了多种候选方案。

#### 1.2.3.2 稀疏化类方法

稀疏化类方法通过减少参与通信的梯度分量数量来压缩通信量，仅对被选中的分量发送索引及其取值，其余分量在解码端视为零。本课题已实现的稀疏化方法主要包括 Top‑k、Random‑k、Threshold‑v 以及 Sketched‑SGD 等。

Top‑k 稀疏化方法保留梯度向量中绝对值最大的 \(k\) 个分量，其余置零。记 \(|g|_{(1)} \ge \cdots \ge |g|_{(d)}\) 为 \(|g|\) 的非增排列，则有
\[
(\mathrm{topk}(g))_i =
\begin{cases}
g_i, & i\ \text{属于前 } k\ \text{大坐标},\\
0, & \text{否则}.
\end{cases}
\]
实现时通常令 \(k = \lfloor \rho d \rfloor\)，其中 \(\rho\) 为目标稀疏率。Top‑k 为有偏压缩，理论与实践均表明需配合误差反馈以保证长期收敛性质。本课题在 FSDP 中同时支持两种通信形态：其一是对补零后的稀疏向量直接执行 `reduce_scatter(sum)`；其二是仅发送选中坐标的索引与取值，经 all-gather 后在本地合并，再按 rank 切分，后一种在 \(\rho \ll 1\) 时可显著降低通信字节数。

与 Top‑k 相比，Random‑k 随机稀疏化更强调无偏性。Random‑k 从 \(\{1,\ldots,d\}\) 中均匀随机选取 \(k\) 个分量并保留其取值，其余置零；为保持无偏性，对被选中分量乘以缩放因子 \(d/k\)，即
\[
(\mathrm{randk}(g))_i =
\begin{cases}
(d/k)\cdot g_i, & i \in \omega,\\
0, & \text{否则},
\end{cases}
\quad \omega \sim_{\mathrm{u.a.r.}} \binom{[d]}{k}.
\]
Random‑k 的计算复杂度较低，易于并行实现，但方差与压缩率直接相关。其在 FSDP 下的通信与解码流程与 Top‑k 基本一致，同样支持稠密与稀疏两种通信模式。

Threshold‑v 方法通过双阈值控制稀疏化程度。该方法使用正、负两个阈值 \(v_+ \ge 0\)、\(v_- \ge 0\)，仅保留满足 \(g_i \ge v_+\) 或 \(g_i \le -v_-\) 的分量：
\[
(\mathrm{thresh}(g))_i =
\begin{cases}
g_i, & g_i \ge v_+ \text{ 或 } g_i \le -v_-,\\
0, & \text{否则}.
\end{cases}
\]
阈值可以由用户显式给定，也可以根据目标稀疏率从当前梯度的经验分位数自适应估计。在本课题实现中，当未指定显式阈值时，系统会根据目标稀疏率近似选取对应分位数作为对称阈值。与 Top‑k 相比，Threshold‑v 避免了完整排序，计算复杂度更低，但对阈值的选择更为敏感。通信与合并环节同样支持稠密 `reduce_scatter` 与稀疏索引–取值两种形式。

Sketched‑SGD 则代表了基于 sketch 的整体稀疏化思想。该方法通过将梯度映射到 Count Sketch 等数据结构中来压缩维度，并利用 sketch 的线性性在通信侧合并各 worker 的 sketch，再从合并后的 sketch 中恢复近似 top‑k 坐标。形式上，设 Count Sketch 由深度 \(d_s\)、宽度 \(w_s\) 以及两组哈希函数 \(h_j : [d] \to [w_s]\)、符号函数 \(s_j : [d] \to \{-1,1\}\)（\(j=1,\ldots,d_s\)）定义，则第 \(j\) 行的 sketch 向量为
\[
S_j(g)[\ell] = \sum_{i : h_j(i) = \ell} s_j(i)\, g_i,\quad \ell = 1,\ldots,w_s,
\]
整体 sketch 记为 \(S(g) = (S_1(g),\ldots,S_{d_s}(g))\)。利用 Count Sketch 的线性性，有 \(S(g^{(1)} + g^{(2)}) = S(g^{(1)}) + S(g^{(2)})\)，因此多 worker 情况下可以先对各自的 sketch 做 all-reduce(sum)，再在合并后的全局 sketch 上恢复近似 top‑k 坐标。HEAVYMIX 策略在全局 sketch 上给出每个坐标的平方幅值估计 \(\hat{g}_i^2\) 及总能量估计 \(\widehat{L}_2^2 \approx \|g\|_2^2\)，并据此构造重度坐标集合
\[
H = \bigl\{\, i : \hat{g}_i^2 \ge \widehat{L}_2^2 / k \,\bigr\},
\]
若 \(|H| < k\) 则再从其余分量索引中随机补足到 \(k\) 个。典型流程包括：各 rank 对本地梯度计算 Count Sketch 得到低维 sketch 表示；通过 all-reduce 对 sketch 求和得到全局 sketch；在全局 sketch 上应用 HEAVYMIX 得到集合 \(H\)；最后对集合 \(H\) 中对应的梯度分量执行第二轮精确值通信（如 all-gather），得到这些分量上的精确梯度总和。本课题实现了单轮与双轮两种模式：单轮模式仅使用 Count Sketch 恢复近似稀疏梯度并走稀疏通信；双轮模式则完整包含 HEAVYMIX 步骤，更贴近原论文设定。与逐分量稀疏化方法相比，Sketched‑SGD 在高维场景下具备更优的理论通信复杂度，但在实际实现中需要平衡 sketch 尺寸、恢复精度与额外的计算开销。

总体而言，量化类与稀疏化类方法分别从“降低比特数”和“减少参与通信的梯度分量数”两个维度压缩后向梯度通信量。本课题在统一的 FSDP 通信压缩框架下实现了上述多种算法，并通过统一的评估指标对其压缩比、通信耗时、训练效率与收敛性能进行对比，为后续章节的实验分析和方案选择提供了基础支撑。
